# Sales Insights Dashboard

## Project Overview
This project analyzes large-scale retail sales data to identify regional performance trends and revenue growth opportunities. The focus is on KPI-driven analysis and automated reporting.

## Key Highlights
- Analyzed 100,000+ retail transactions
- Built interactive Power BI dashboards for sales KPIs
- Automated weekly reporting using SQL queries and Excel pivot tables

## KPIs Tracked
- Total Sales
- Profit Margin
- Regional Performance
- Customer Retention

## Tools & Technologies
- Power BI
- SQL
- Microsoft Excel

## Outcome
The dashboard enables business stakeholders to monitor sales performance and make informed, data-driven decisions efficiently.
